# GymLog - UI Guide

Version: 0.2
Status: Draft

---

# 1. User Experience

Dark mode only.

Large buttons.

One-hand operation.

Maximum two taps to log a set.

Previous values visible during logging.

Default weight and reps filled automatically from previous workout.

---

# 2. Screen Behavior

The main workflow should keep the user close to the active workout screen.

The app should minimize typing and make common actions reachable quickly.

---

# 3. Settings Behavior

The settings area should allow editing gyms, body part groups, global gym detection radius, import, export, theme, backup, and restore.
